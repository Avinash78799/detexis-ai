01 / REQUEST INSPECTOR

Read the request.

Runs the same single-request rules used by Shield monitoring. Paste only a sample you are allowed to inspect. Remove secrets and personal data first.

What this checks

SQL injection, executable HTML patterns, path traversal, shell syntax, nonpublic URL targets, scanner user agents and sensitive-path probes. Traffic-dependent rules and site canaries require a connected sensor. Named secret query fields are redacted before matching, so attacks inside those fields are excluded.

02 / FILE SIGNATURE SCANNER

Check the file.

Uses a separate ClamAV engine on the operator’s computer. Files are sent for scanning, never executed, and not retained by this tool. Do not submit confidential material.

Checking scanner readiness…

How to read a result

A detected signature needs investigation. No signature detected does not prove safety. Scan limits or encryption may require review. Missing, stale or unavailable engines produce no safety verdict. This is not a sandbox or a scan of your whole device.

Analysis without invented certainty.

Samples are not saved as incidents or used to train a model. Live monitoring and historical correlation run through your connected sensor. Read data handling →
