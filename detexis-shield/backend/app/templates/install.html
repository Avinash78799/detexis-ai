1. Prepare your application

You need a persistent Python 3.10+ application using FastAPI, Starlette or Flask, and outbound HTTPS access to your Shield service. This SDK does not support short-lived Vercel/serverless functions, Django or Node/Express yet.

In your workspace, add the exact website hostname you own or have permission to monitor. Save the sensor key and site salt displayed once. Sensor monitoring is separate from domain verification, which is required for scans.

Install the pinned SDK source using Git and pip in your application's virtual environment. This version is available from the repository; a public PyPI release is not claimed.

python -m pip install "detexis-shield @ git+https://github.com/Avinash78799/detexis-ai.git@0369c1239ffc1d5b015179c6b36c7ba28ab37426#subdirectory=detexis-shield/sensor-sdk"

Set these values using your hosting provider's secret/environment settings. Restart the application after changing them.

SHIELD_URL
Your Shield workspace's HTTPS origin, without /app or a trailing path. A temporary tunnel URL changes when restarted; use a stable service URL for real monitoring.
SHIELD_API_KEY
The dxs_… key for this website. Keep it on the server and out of Git, browser JavaScript and support messages.
SHIELD_SALT
The stable private salt saved at website creation. Use the same value across this website's processes. To replace a lost salt, generate a new value with python -c "import secrets; print(secrets.token_urlsafe(32))" and save it in your secret settings. Replacing it changes IP correlation identities.

The snippets read environment variables. They do not load a .env file automatically. Do not paste credentials into these source files.

2. Add the middleware

Choose the example for your framework. Add the middleware once in an existing app, or save one complete example below as app.py.

FastAPI / Starlette

import os
from fastapi import FastAPI
from detexis_shield import ShieldMiddleware

app = FastAPI()
app.add_middleware(
    ShieldMiddleware,
    api_url=os.environ["SHIELD_URL"],
    api_key=os.environ["SHIELD_API_KEY"],
    site_salt=os.environ["SHIELD_SALT"],
)

@app.get("/")
def home():
    return {"ok": True}

For this complete example, install fastapi uvicorn, then run python -m uvicorn app:app --port 9000. In an existing Starlette app, use the same app.add_middleware(...) call.

Flask / WSGI

import os
from flask import Flask
from detexis_shield import ShieldWSGIMiddleware

app = Flask(__name__)
app.wsgi_app = ShieldWSGIMiddleware(
    app.wsgi_app,
    api_url=os.environ["SHIELD_URL"],
    api_key=os.environ["SHIELD_API_KEY"],
    site_salt=os.environ["SHIELD_SALT"],
)

@app.get("/")
def home():
    return {"ok": True}

For this complete example, install flask, then run python -m flask --app app run --port 9000 for local development. Use a production WSGI server when hosting real traffic. Create the wrapper inside each worker process; do not use Gunicorn --preload with this SDK's background thread. Flask's development reloader can start extra sender threads.

3. Confirm the connection

  1. Start or restart your application, then open a normal page on that application.
  2. Return to your Shield workspace and choose Check sensor connection beside this website. Batches normally flush after three seconds; the first heartbeat takes about one minute.
  3. Check the website dashboard for request activity. Normal traffic may produce no incident. A heartbeat proves connectivity, not continuous delivery of every request.

If events are missing, check the HTTPS URL, key, environment settings and outbound network access. A revoked key must be replaced. Request processing delays may require the Shield operator to check workers and Redis.

Know what is collected

The sensor sends method, path, named-secret-redacted query, user agent, status, latency, flags, derived features and a per-site daily salted IP hash. It does not capture request bodies, cookies or authorization headers. Paths, user agents and unrecognized query fields can still contain personal data; review your application's URLs and privacy needs before connecting real users.

Monitoring never blocks requests. When Shield is unavailable or the bounded buffer fills, events can be dropped and your site keeps serving. Default event retention is 30 days; ask your Shield operator about its configured retention and backups.
