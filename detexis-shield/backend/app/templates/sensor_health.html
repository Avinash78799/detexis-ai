How heartbeat monitoring works

A signal opens after a previously reporting site misses heartbeats for more than three minutes, while a sensor key remains active. Maintenance checks once a minute, up to 100 transitions per tick. New keys get three minutes for setup before a new gap can open; creating a key does not close an existing gap. Quiet request traffic alone does not trigger it.

This does not prove that your website is down or under attack. Check the host application, sensor sender, credentials, backend availability and network. Shield cannot send a downtime signal while its own computer or backend is offline.

Sites that have never sent a heartbeat remain in onboarding. Multiple sensors for one site share its latest heartbeat; one healthy instance can mask another instance's gap.
